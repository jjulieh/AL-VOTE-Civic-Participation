# AL-VOTE: Voter Turnout & Participation Trends

This project was completed as part of the University of Maryland INST490 Capstone in collaboration with the Southern Poverty Law Center (SPLC).

## Project Overview

The AL-VOTE project examines voter participation across 43 Alabama counties using election results, voter registration, demographic participation, and Citizen Voting Age Population (CVAP) data from the 2020 and 2024 election cycles.

The analysis also provides deeper examination of eight high-priority counties:

- Talladega
- Tuscaloosa
- Etowah
- Calhoun
- Chambers
- Madison
- Jefferson
- Shelby

## Project Focus

The analysis examines:

- Changes in voter participation from 2020 to 2024
- Participation among Black and Latinx voters
- Black–White participation gaps
- Voter registration compared with election participation
- Participation patterns by age and gender
- Differences between high-priority counties and the broader 
  43-county study area

## Data Sources

Data were obtained from:

- Alabama Secretary of State Election Data
- Redistricting Data Hub Citizen Voting Age Population (CVAP) data

## Methods

Data cleaning and preprocessing were completed in Python using pandas in Google Colab.

Statistical analysis and visualizations were completed in R using tidyverse and ggplot2 in Google Colab.

## Repository Structure

- `notebooks/` – Data cleaning and analysis notebooks
- `data/` – Cleaned and raw datasets used for analysis
