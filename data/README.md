# Data

This folder contains the raw and cleaned datasets used for the AL-VOTE
voter turnout and participation analysis.

The project uses election, voter registration, and demographic
participation data from the Alabama Secretary of State, along with
Citizen Voting Age Population (CVAP) estimates from the Redistricting
Data Hub.

- `raw/` contains the original source files used for the project.
- `cleaned/` contains the processed datasets used in the final R analysis.

Data cleaning and preprocessing were completed in Python using pandas
in Google Colab.
