# Cleaned Data

This folder contains the final cleaned datasets used for the AL-VOTE
analysis.

Raw data were cleaned and validated in Python using pandas in Google
Colab. Cleaning included filtering to the 43 project counties,
standardizing county names and variable names, converting relevant
fields to numeric values, checking for missing or duplicate records,
and combining corresponding 2020 and 2024 datasets.

These cleaned CSV files were then imported into R in Google Colab for
statistical analysis and visualization.

For complete cleaning procedures, see the project's data cleaning
notebook in the `notebooks/` folder.
