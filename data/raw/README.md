# Raw Data

This folder contains the original source datasets used in the AL-VOTE
analysis for the 2020 and 2024 election cycles.

## Data Sources

### Alabama Secretary of State
Data include election results, voter registration, and demographic
voter participation information.

### Redistricting Data Hub
Data include Citizen Voting Age Population (CVAP) estimates used to
calculate estimated voter participation rates.

The files in this folder are preserved in their original form. Cleaning,
standardization, filtering, and validation steps are documented in the
project's data cleaning notebook.
